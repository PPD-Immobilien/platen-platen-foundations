# Platen-Platen Foundations

Erstelle die vollständige erste Version der Website für Platen-Platen-Diehl eGbR exakt nach den Vorgaben des Nutzers. Wichtig: statische, selbst hostbare React/Vite-Website ohne Datenbank, Auth, Backend, kostenpflichtige APIs oder notwendige externe Services. Inhalte im Frontend; Kontaktformular validiert und öffnet eine vorbereitete mailto-E-Mail an platen-platen-diehl-gbr@gmx.de. Umsetzen: hochwertige, minimalistische responsive Corporate Website in Weiß, Dunkelblau, neutralen Grautönen und Inter; Header mit Logo-Platzhalter und mobiler Navigation; alle benannten Bereiche/Anker, Gründerkarten mit klaren Platzhaltern für später hochzuladende echte Fotos, separate Kontaktseite, Impressum- und Datenschutz-Platzhalterseiten, SEO Title und Meta Description. Verwende nur realistische Architektur-Bildflächen, keine KI-Personen/Stock-Portraits; Gründerbilder als lokale deutlich beschriftete Foto-Platzhalter, die einfach ersetzt werden können. Sorge für ruhige, persönliche Immobilien-Ankäufer-Positionierung, keine Makler-/Luxus-/Investmentoptik. Stelle sicher, dass der Produktionsbuild vollständig statisch exportierbar und auf NAS-Webserver hochladbar ist.
